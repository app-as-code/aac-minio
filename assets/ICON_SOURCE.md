# Icon source

Icons are downloaded from the homarr-labs dashboard-icons collection
(repository `homarr-labs/dashboard-icons`, served via jsdelivr). No icon was drawn or
modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/minio.svg` | Default |
| `icon-light.svg` | `svg/minio.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/minio-light.svg` | Light-colored logo for dark backgrounds (dark mode) |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/minio.svg
- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/minio-light.svg
